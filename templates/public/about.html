Built as a real backend, not a CRUD demo.

Eligibility is a service. Status changes write history. Notifications land even if the worker is down. The REST API is what the dashboards actually call.

How a job moves

Draft → pending approval → approved/active → closed. Students only see active jobs whose deadline has not passed.

How an application moves

Applied → under review → shortlisted → interview scheduled → selected, or rejected at valid points. Illegal transitions are rejected by the backend.
